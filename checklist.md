## ✅ Checklist — Para Tirar Nota Máxima

Use este checklist antes de entregar:

### Entrega e Documentação

- [x] Arquivo `entrega.txt` com nome, RM de todos e links
- [x] Repositório GitHub público e acessível
- [x] `README.md` completo com descrição, prints e instruções de execução
- [x] Vídeo de até 3 minutos demonstrando o app funcionando (Preparado para gravar)

### Estrutura e Navegação

- [x] Projeto criado com Expo (React Native)
- [x] Expo Router implementado com pelo menos 3 rotas/telas
- [x] Navegação entre telas funcional (stack, tabs ou drawer)

### Gerenciamento de Estado

- [x] `useState` utilizado em pelo menos 2 componentes
- [x] `useEffect` para carregamento de dados ou efeitos colaterais
- [x] **Context API** implementada para estado global

### Persistência de Dados

- [x] **AsyncStorage** utilizado para salvar e recuperar dados localmente

### Formulários

- [x] Pelo menos um formulário com campos e **validação funcional**

### Dashboards e Dados

- [x] Pelo menos **2 telas de dashboard** com visualização de dados relevantes para a solução
- [x] Dados apresentados de forma visual (gráficos, cards, indicadores, listas dinâmicas)

### Qualidade Visual e Técnica

- [x] UI coerente, limpa e com identidade visual relacionada ao tema
- [x] Componentes reutilizáveis separados em arquivos próprios
- [x] Código organizado (sem arquivos gigantes, sem lógica misturada com UI)
- [x] Sem erros ou warnings críticos no console

### Conexão com o Tema

- [x] A solução está claramente conectada ao tema de **Indústria Espacial**
- [x] O app apresenta o problema e a solução proposta pelo grupo de forma compreensível
